# the vacuum command is disabled

`aqua >= v2.63.0`

You may face the error when you run `aqua vacuum` or `aqua vacuum --init`.

e.g.

```console
$ aqua vacuum
ERR aqua failed doc="https://aquaproj.github.io/docs/reference/codes/007" error="the vacuum command is disabled" program=aqua
```

## What does this error mean?

This error occurs when the environment variable `AQUA_DISABLE_VACUUM` is `true`.

[aqua vacuum](/docs/guides/vacuum) removes installed packages which haven't been used for over the expiration days, based on packages' last used date times recorded by aqua.
If `AQUA_DISABLE_VACUUM` is `true`, aqua doesn't record last used date times, so the recorded date times get stale.
Running `aqua vacuum` in that state would remove packages which are actually in use, so aqua rejects the command instead.

## How to solve the error

If you want to run `aqua vacuum`, please unset the environment variable `AQUA_DISABLE_VACUUM`.

```sh
unset AQUA_DISABLE_VACUUM
```

Note that packages' last used date times aren't recorded while `AQUA_DISABLE_VACUUM` is set, so `aqua vacuum` may remove packages in use.
Please run [aqua vacuum --init](/docs/guides/vacuum) to record the current date time as the last used date time of installed packages before running `aqua vacuum`.
